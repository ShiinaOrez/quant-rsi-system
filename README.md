# Quant RSI System

在模型驱动的量化系统之上，通过递归自我改进（Recursive Self-Improvement，RSI，暂定含义）迭代量化专用后训练模型。

项目目标：可扩展、可执行、可复现的量化 Benchmark；可运行的交易系统；可追溯的模型权重与训练流程；可评估和回滚的 RSI 迭代系统。

当前阶段为文献调研。远端仓库初始为空，尚未实现交易、训练或 Benchmark，尚未产生模型权重或复现论文收益。
