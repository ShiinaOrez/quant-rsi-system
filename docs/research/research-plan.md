# 实验与系统设计草案

以下是基于首轮阅读提出的本项目方案，尚未实现。文献依据与版本见 [阅读笔记](literature-review.md)。市场、频率、硬件及既有系统接入方式待确定；远端当前无已有系统代码。

## 两层改进闭环

外循环负责假设、因子/模型代码、执行、验证反馈与下一轮研究（参考 RD-Agent-Quant、AlphaAgent）。内循环负责生成样本、确定性筛选、SFT/DPO 或 RL、产出 checkpoint（参考 ReST、DPO、Trading-R1）。两层分别记录版本，并通过消融确认收益来源。

第一版倾向从日频横截面因子研究切入：输出可解析表达式、评估成本更低，容易保存失败与成功轨迹。直接生成交易决策作为第二条独立任务；金融 QA 作为辅助能力评测。此选择是暂定研究建议。

## Benchmark 契约

| 层 | 输入与输出 | 指标 | 基线 |
| --- | --- | --- | --- |
| 金融能力 | 冻结文本/表格 → 数值或结构化答案 | 数值正确性、证据一致性 | 原始模型、SFT |
| 因子研究 | 时点数据与研究预算 → DSL 因子 | 可执行率、IC/RankIC、相关性、净收益 | 固定因子库、固定模型生成 |
| 组合交易 | 可用信息与持仓 → 目标权重/订单 | 净收益、Sharpe、回撤、换手、暴露 | 现金、等权/买入持有、简单策略、传统预测模型 |
| RSI | 相同数据与预算 → 多轮模型/系统 | 各轮样本外增益、失败率、算力与调用成本 | 无迭代、仅记忆、仅外循环、仅权重更新、完整闭环 |

1. 每个 task 固定数据快照、股票池与退市处理、决策时点、动作空间、交易日历、成本、成交规则、随机种子、依赖和评估版本。新增市场通过适配器扩展。
2. 训练、搜索验证、晋级验证与最终测试按时间排列；标签有前瞻窗口时，对边界做 purge/embargo。预处理与标签阈值仅在训练区间拟合。
3. RSI 只能访问训练/搜索反馈。晋级集限制使用次数并记录所有试验；最终测试由独立入口运行，结果不能回流训练。走完一个前推窗口后，新增历史数据的权限按明确规则开放。
4. 数据须记录 `event_time`、`available_at` 与版本，财报按实际可用时间对齐。收盘生成的动作最早下一可成交时点执行，价格规则显式配置。
5. 模型预训练知识可能含历史结果；仅隔离输入不等于消除污染。记录模型发布日期/已知知识截止，优先补充模型冻结后的前瞻 paper trading 验证。
6. 固定年化约定、无风险利率、收益与回撤符号；报告扣费前后结果、多随机种子及跨时间窗口结果。按时间 block bootstrap 估计不确定性，保留全部搜索预算和失败实验。

## 从反馈到权重

每条研究轨迹至少保存：数据/任务哈希、模型与提示词版本、假设、候选表达式或代码、执行日志、评分组成、访问过的数据区间、生成时间及种子。

先检查可执行性、时点合法性、风险限制与去重，再根据多个验证窗口的稳定表现筛选。偏好对必须共享任务、信息和预算；没有可靠差异的候选可标为平局或丢弃。收益只是一种信号，不能奖励虚构证据或无效代码。

第一阶段比较原始模型、SFT 与过滤自训练；再加入 DPO。只有评分器与数据契约稳定后再比较 GRPO，避免同时引入长上下文、多 agent 和复杂 RL。固定 teacher 与评分器版本，对 judge 抽样人工审查。

每轮保存父 checkpoint、基础模型 revision、adapter/权重哈希、数据清单、训练命令、超参数、依赖、硬件、成本与评测报告。晋级阈值预先声明；风险或净表现不达标时保留原模型并记录失败。仓库放清单，小型权重或大权重的外部存储位置按容量另行设计。

## 可运行系统与实施顺序

统一 `data → features → model → portfolio → risk → execution → ledger` 接口，回测与 paper trading 共享策略、风险规则和账本。执行端处理成交、费用、拒单、重试和持仓对账；研究模型不能通过文本输出绕过仓位限制。

1. 核验文献工件与既有模型系统入口；选择一个市场和日频任务。
2. 实现离线一条命令可运行的 Benchmark 与传统基线，固定数据快照，保存订单及净值。
3. 接入固定 LLM 和可执行因子 DSL，收集研究轨迹。
4. 运行小规模 SFT/过滤自训练与 DPO，发布首轮 checkpoint 清单及消融报告。
5. 加入受预算约束的 RSI 调度、晋级与回滚，做多轮前推实验。
6. 接入 paper trading 检验成交与数据延迟，扩展市场和策略任务。

下一阶段的完成标准：从干净环境按文档运行得到固定基线报告，能复核每笔订单与成本，最终测试反馈不进入研究循环。模型训练和 RSI 属于后续阶段，本轮仅建立研究依据。
